# 🪙 팀 지분 베스팅 (야매 베스팅)

4인 팀이 **2주마다 각자 한 일을 기록**하면, **AI(Deepseek)가 기여도를 평가**하고,
그 결과에 따라 **지분을 자동으로 조정**해주는 앱입니다.
일 안 한 사람의 지분을 떼어 열심히 한 사람에게 주는 간이 베스팅 개념을 구현했습니다.

## 팀 초기 구성

| 팀원 | 역할 | 초기 지분 |
|------|------|-----------|
| 하주원 | 대표 · 기획/개발 | 40% |
| 이주영 | 영업 | 20% |
| 오준서 | 투자유치 | 20% |
| 이건희 | 재무관리 | 20% |

## 지분 조정 규칙

- 합계는 **항상 100%** 를 유지합니다 (제로섬 — 뺏은 만큼만 줍니다).
- **1회 평가(2주)당 1인 최대 변동폭은 ±5%p** 입니다.
- 팀 평균보다 잘한 사람은 지분을 얻고, 못한 사람은 잃습니다.
- 지분은 0% 아래로 내려가지 않습니다.
- 점수 차가 작으면 변동도 작고, 차가 크면 최대 ±5%p까지 벌어집니다.

계산 로직은 [`lib/equity.js`](lib/equity.js)에 있습니다.

## 실행 방법

```bash
# 1. 의존성 설치
npm install

# 2. 환경변수 설정
cp .env.example .env
#   .env 파일을 열어 DEEPSEEK_API_KEY 를 채워넣으세요.
#   (키가 없어도 '목(mock) 모드'로 동작은 하지만, 실제 평가가 아닙니다.)

# 3. 실행
npm start
```

브라우저에서 `http://localhost:3000` 접속.

## 사용 흐름

1. 각 팀원이 **이번 2주간 한 일**을 자기 칸에 구체적으로 적습니다 (자동 저장).
2. `🤖 AI 평가 & 지분 조정 실행` 버튼을 누릅니다.
3. Deepseek가 각자 기록을 0~100점으로 평가하고, 규칙에 따라 지분이 조정됩니다.
4. 조정 결과와 총평이 표시되고, 회차가 마감되어 히스토리에 남습니다.
5. 다음 2주 뒤 다시 반복.

> 팁: 성과·수치·결과물 위주로 구체적으로 적을수록 정확하게 평가됩니다.
> 기록이 비면 낮은 점수를 받아 지분이 깎입니다.

## 환경변수

| 변수 | 설명 | 기본값 |
|------|------|--------|
| `DEEPSEEK_API_KEY` | Deepseek API 키 (필수, 없으면 목 모드) | — |
| `DEEPSEEK_MODEL` | 사용할 모델 | `deepseek-chat` |
| `PORT` | 서버 포트 | `3000` |

## 기술 스택

- **백엔드**: Node.js + Express (API 키는 서버에만 보관, 프론트 노출 없음)
- **저장소**: JSON 파일 (`data/data.json`, 자동 생성 · git 제외)
- **프론트엔드**: 바닐라 JS + CSS (빌드 불필요)
- **AI**: Deepseek Chat Completions API

## 데이터 초기화

앱 하단의 `전체 초기화` 버튼을 누르면 지분·기록·히스토리가 초기 상태(40/20/20/20)로 돌아갑니다.
